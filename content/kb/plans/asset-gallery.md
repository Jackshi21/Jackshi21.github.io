# 大场景、模型与材质实现计划

2026-11-13，先按[资源与规范笔记](../reading/assets-gltf.md)明确范围，再实现。

**状态**：本轮已完成，[实测与边界](../experiments/asset-gallery.md)。

## 本轮范围

- 新增比 Cornell 更大的 Gallery 展示场景，布置地面、背景、矩形面光源和不同材质的测试物体，提供对应相机和移动速度。
- 支持静态、三角形、不透明 glTF 2.0 / GLB：网格与节点实例、位置、法线、UV0、局部到世界变换；通过命令行载入并配置位置、旋转和缩放。桌面面板提供打开模型入口。
- glTF metallic-roughness 材质：基础色、金属度、粗糙度，以及 PNG/JPEG 的基础色、金属度／粗糙度、切线空间法线贴图。保留原 Cornell 漫反射与导体分支，避免改变既有实验定义。
- 本轮纹理建立可复查的 GPU 基线：保存原图尺寸，通过存储缓冲区进行双线性采样，支持 repeat / clamp / mirrored-repeat。尚不包含 mipmap、各向异性、压缩纹理或完整 glTF 材质扩展。
- 遇到不支持的动画／蒙皮、非三角形、透明材质和必需扩展给出明确错误，避免以成功导入掩盖缺失。空间复用暂保留在原实验场景，外部资产先验证完整路径积分器。

## 接入与验收

1. 扩展共享 Scene 与显式 GPU 结构；加载后仍复用每网格 BLAS 与节点 TLAS 实例。
2. 解析默认场景和节点层级，校验 accessor、索引、非有限值与退化变换。保存材质和贴图映射、资产文件路径和场景规模统计。
3. PBR 的 BRDF 评价与方向采样使用一致的混合 PDF；颜色贴图先转线性再插值。法线贴图处理 UV 方向、几何侧与插值法线。
4. 下载 Poly Haven CC0 木桌 1K glTF 及全部依赖，记录来源、许可证与文件校验。该资产验证实际木纹、法线和材质通道；生成有贴图／关闭贴图对照。
5. 用自建小型 GLB、外部 glTF 和非法文件验证变换、UV、材质、资源缺失与错误路径；GPU 法线视图与 CPU 主射线 oracle 对照。
6. 构建与现有 CTest，重跑受影响的积分器／材质检查、累积状态和 Vulkan 同步验证。生成大场景与模型截图，回填实验、使用方式、资源下载和续接进度。

## 边界

首个场景的目标是让外部模型和材质真正可用。动画、透明玻璃、环境贴图照明、材质编辑器、实时热重载与移动端资产选择后续独立推进。本轮所有不透明表面沿用渲染器的双面着色策略；不声称完整实现 glTF 显示规范。用户后续提供的资源将在此通路上验证。
