# 最小 RIS 基线实现计划

**状态** · 已完成桌面实现、验证与[实验回填](../experiments/ris-baseline.md)。

依据[第二篇阅读笔记](../reading/restir-ris.md)，先在每个着色点实现独立候选的 RIS，沿用现有多光源房间与挡板。第一轮用完整可见贡献打分，保留现有 MIS 的两项分解，验证重采样后的平均能量与代价。

## 接入方式

- 增加桌面参数 `--ris-candidates N`，范围 0–64。0 沿用现有直接光照采样，正数表示每个着色点生成 N 个候选。提议分布继续由 `--light-sampling uniform|power` 选择，参数进入已有 push constant 的空字段。BSDF-only 与 RIS 同时启用时报告配置冲突。
- 将当前单次显式光源采样提取成共享函数，返回经过遮挡查询、原始 light PDF 和 MIS 权重后的 RGB 贡献估计。RIS 逐个调用这个函数，用该估计的线性亮度作为重采样权重。蓄水池保留被选候选的 RGB 估计，并乘累计权重除以候选数和被选权重。权重全零时返回零。
- BSDF 延伸射线命中发光面的贡献，继续使用原先互补的 MIS 权重。RIS 采样的是原 NEE 项的积分，原提议 PDF 只参与这个固定积分项的计算。最终保留下来的样本携带贡献权重，保持整项的期望。
- 分开维护候选生成与蓄水池替换的随机数流，使 N=1 时能直接和现有积分器对照。记录实际阴影射线数，以及从本次累积开始的采样 dispatch 总 GPU 时间。显示更新、读回与重复保存不会重复累加采样时间。

## 验收与实验

1. N=1 与原直接光照积分器，在相同种子下的 PFM 逐通道误差低于 0.00001，实际阴影射线数一致。全零权重像素应输出有限的零贡献。
2. 两个多光源场景分别使用均匀和功率提议分布，以三个种子比较 N=4 与原方法。保留整体和挡板阴影的误差、平均能量、实际阴影射线数及 GPU 时间。
3. 分别展示相同 spp 和近似相同阴影射线预算的结果。N=4 每次增加候选及其遮挡查询，等预算时应减少 spp。参考图使用独立高样本直接光照图，并检查参考图噪声。
4. 复跑现有五项 CTest 与单灯积分器回归。额外用多反弹和金属场景检查 RIS 与现有 BSDF 延伸的组合，开启 Vulkan 同步验证核对资源访问。

当目标等于被估计项的亮度时，RIS 输出的亮度应等于这些候选贡献亮度的平均值。这给出一个正确性检查，也意味着第一版可能接近直接平均候选的效果。实验需要同时展示射线和耗时，才能判断本机上的实际收益。[课程笔记 §3.3，Tip 3.10](https://intro-to-restir.cwyman.org/presentations/2023ReSTIR_Course_Notes.pdf#page=20)
